# 技能試験・自動因子設計 Ver.2.1 試作

## 追加内容
- レース場・回り・季節・バ場・距離条件・天候を複数選択
- 育成ウマ娘の登録候補を追加し、選択時に初期適性を切り替え
- 自由入力時は初期適性をGへ戻して手動編集可能
- 共通G1ボーナス向け出走スケジュールと家系7人の対応人数表示
- 各祖父母・曾祖父母に推奨白スキルを表示
- 習得チェック、白因子★入力、次世代への簡易継承率表示
- 実在白スキルの検索・予測候補選択
- 技能試験で使いやすい候補を上位表示
- Safari内自動保存の説明、共有シート経由のファイル保存、通常ダウンロード、読み込み

## 継承率表示
白スキル因子の基礎継承率（★1=3%、★2=6%、★3=9%）に、
登録済みの候補順位と共通G1対応数を加えた簡易推定です。
ゲーム内部の正確な確率を保証するものではありません。
