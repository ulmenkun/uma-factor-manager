# ウマ娘 技能試験・自動因子設計 Ver.4.4 r7

Ver.4.4は、Ver.4.3で追加した赤因子・ダートG1相性ローテ設計を引き継ぎつつ、起動時に発生していた表示エラーを修正した再構成版です。

## Ver.4.4 r7（2026-09-08）

- 技能試験向けサポカTOP5を「単体順位」から「5枚全体の組み合わせ評価」へ変更。既に別カードで取れる高効率スキルは大幅減点し、取得できるスキル種類数を優先
- 選択中の育成シナリオを編成評価へ反映。トレセン軒は新SSR駿川たづな＋スピード2＋賢さ1を軸、BEYOND DREAMSはSSRカジノドライヴ＋5タイプ以上・スピード1〜2枚を優先
- TOP5と下のおすすめサポカ自動編成で同じ「重複回避」評価を使用。所持5枚＋フレンド1枚の制約内で未取得の高効率スキルを増やすカードを優先
- TOP5は「自動編成」を押した時に更新。育成シナリオを変更した場合はいったんクリアし、再度自動編成するまで旧ランキングを表示しない
- TOP5欄はデフォルト非表示。「技能試験向けサポカTOP5を見る」を押した時だけ展開

## Ver.4.4の修正

- Ver.4.3で欠落していた `finalTargetRedStars()` を復元し、起動直後の「読み込みエラー」を修正
- クリスエスの赤因子設計を **本育成開始時：マイルA・追込B** で固定
- 追込の最終目標適性は従来どおりA。開始時Bから育成中継承でAを狙う
- Ver.4.3の家系図、赤因子配分、ダートD逆算、G1相性ローテ機能を維持
- バックアップファイル名をv4.4へ更新

## 既定のクリスエス設計

- [Jetblack Automaton] シンボリクリスエス
  - 初期：マイルE・追込D
  - 赤因子による本育成開始時：**マイルA・追込B**
  - 最終目標：マイルA・追込A（追込Aは育成中継承を狙う）
- 直親は固定せず、技能試験向けに **継承進化の評価点・実相性・親同士相性・共通G1・赤因子自作難度** から自動再計算
- r6の標準計算では **マイル側エピファネイア＋追込側ステイゴールド** を第一候補として表示
  - クリスエスとの相性：エピファネイア18、ステイゴールド23
  - 親同士：エピファネイア×ステイゴールド20 → 3者基礎相性合計61
  - 比較：ラインクラフト＋ステイゴールドは 8＋23＋9＝40
- 継承進化は技能試験用の検証値 **1個1764点 / 200SP** として重視。発動条件そのものより査定を優先する
- エピファネイアはマイルE・ダートGのため、6枠だけでは開始時マイルA＋ダートDを同時達成できない。r6では **マイルB＋ダートD** で開始し、育成中のマイル継承で終了時Aにしてマイル赤因子を狙う設計
- ステイゴールドは追込側A＋ダートDを同時に満たす赤因子配分を自動設計
- ダートG→Dには合計7★以上が必要。★3中心では3枠（9★）を基本に割り当て
- 継承進化は直親からのみ。本人未所持ならフレンド因子を借りても進化不可なので、所持設定を入力した場合は自動ランキングに反映

## 家系図の赤因子表示

- 親・祖父母・曾祖父母ごとに赤因子の種類と★数を表示
- その時点で選ばれた直親をダートD以上にするため、祖父母・曾祖父母の6因子で現在何★ダートを積んでいるかを表示
- 祖父母自身をダートDで周回する場合は、表示中の曾祖父母2人だけで不足する分を「表示外の父母4枠であと何★必要か」と逆算表示
- 候補変更後は下位候補を再計算

## 相性ローテ

- 親2人が共通して勝ちやすいG1を自動選択
- 相性上昇目的でダートG1を優先
- 赤因子による育成開始時の適性上昇を加味して出走可否を判定
- 育成目標・シナリオ競合と同ターンのレースは除外
