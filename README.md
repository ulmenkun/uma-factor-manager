# 技能試験・自動因子設計 Ver.2.8 試作

## 変更点
- 実在するレース場○だけを登録し、川崎・船橋・盛岡レース場○を削除
- 緑○、距離・脚質直線／コーナー、ダート直線／コーナーを初期選択
- 伏兵○、一匹狼、枠番、天候、脚質のコツ○などを追加
- 短距離、逃げ、ダート、デバフを含む白スキル候補を大幅追加
- 個体編集を「候補」「因子」タブに分離
- 因子タブを「スキル因子」「レース因子」に分離
- 最上部で選択した白因子を各個体へ全件追加可能
- レース因子の取得レース、開催時期、レース場、効果を表示
- レース因子がないG1は「共通G1ボーナス用」と明記
- バックアップ保存の正常確認・最終読込日時を表示

## 注意
継承率％は白因子★、候補順位、共通G1対応数を使った簡易目安で、
ゲーム内部の正確な確率を保証するものではありません。
基礎SPは攻略データを参考にした目安で、ゲーム更新により変わる場合があります。
