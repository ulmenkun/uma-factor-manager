# ウマ娘 技能試験・自動因子設計 Ver.3.3

ブラウザで動くウマ娘の因子設計・サポカ編成・技能試験ポイント試算ツールです。

## Ver.3.3の主な変更

### Webページのボタンから最新情報を収集

ページ下部の **「Webから自動収集して更新」** を押すと、GitHub Actionsをその場で起動します。Actions上でGameToraの公開データを読み取り、`data/latest-data-pack.json` を更新したあと、Webページが完成したデータを自動で読み込みます。

- 定期実行ではなく、ボタンを押した時だけ収集
- 新規SSR・SRサポカと取得スキル名を検出
- 収集の進行状況とGitHub Actionsの実行画面を表示
- 収集完了後に自動適用、または差分確認後に手動適用
- 所持サポカ、家系図、個別編成、ヒントLvなどの利用者データは保持
- 画面を閉じても、同じ端末で再度開けば実行状況を再確認

### 初回だけ必要な設定

1. ZIP内の `.github/workflows`、`tools`、`data` をリポジトリへ配置します。
2. リポジトリの `Settings → Actions → General → Workflow permissions` を **Read and write permissions** にします。
3. 対象リポジトリだけに使えるFine-grained personal access tokenを作り、Repository permissionsの **ActionsをRead and write** にします。
4. Webページの「初回設定・GitHub連携」に、トークンを一度入力します。

トークンは利用者の端末内にのみ保存し、GitHub REST API以外には送信しません。バックアップJSONにも含めません。

### 自動収集の方針

- GameToraの公開マニフェスト、サポートカード一覧、各カード詳細を参照
- 既存の精査済みカード情報・SP・評価点は維持
- 新規で数値未確認のスキルは暫定値として追加
- 暫定値は画面上で確定値と区別
- 公開ページ1件の形式が変わっても、ほかのカードの収集は継続

### 作成済みデータだけ確認する場合

「作成済みデータだけ確認」は、すでにリポジトリにある `data/latest-data-pack.json` との差分だけを確認します。新しい公開情報を取りに行く場合は、必ず「Webから自動収集して更新」を使います。

## Ver.3.1までの主な機能

### サポートカードDB

- SSR 88枚、SR 21枚を収録した初期データ
- 直近1年半のSSR、因子周回向け旧SSR・SR、友人・グループカード
- フォーエバーヤング、新旧たづなを収録
- 手動選択欄に `[スピード]` `[賢さ]` `[友人]` などのタイプを表示
- 選択後の6枠をタイプ別の背景色で表示

### 家系図ごとの個別サポカ編成

③で本育成、親、祖父母、曾祖父母の15対象を切り替えられます。

- 各ウマ娘ごとに別の育成シナリオと6枚編成を保存
- そのウマ娘へ配置した白因子を取得できるカードを優先
- 所持カードから5枚、未所持カードから最適な1枚をフレンド枠へ配置
- 育成ウマ娘本人のサポカと同一キャラクター重複を除外
- ラーメンシナリオでは新SSRたづなを必須候補として扱う

### 白・金スキルと技能試験効率

- 白スキル：適性補正後の基礎評価点＋400
- 金スキル：適性補正後の基礎評価点＋1,200
- 進化スキル：適性補正後の基礎評価点＋1,500
- ◎スキル：追加の固定400点なし
- 効率＝技能試験で増える点数 ÷ ヒントLv反映後の実消費SP

本育成画面では、所持SP内で技能試験ポイントが最大になる組合せを0/1ナップサック法で選びます。

## データ形式

`data/latest-data-pack.json` は次の情報を持つ更新パックです。

- `schemaVersion`
- `version` / `generatedAt`
- `supportCards`
- `skills`
- `removedSupportCardIds` / `removedSkillNames`
- `externalHashes`
- `releaseNotes`

更新パックは本体データへマージされ、ブラウザのローカルストレージへ保存されます。

## 注意事項

- 自動収集は公開ページの構造変更により一部取得できなくなる可能性があります。
- 自動追加された未確認スキルのSP・評価点は暫定値です。精査済み値が配布された場合は更新パックで上書きされます。
- スキルの前提関係、下位・上位スキルの同時取得制限、進化条件、シナリオ固有の細かな育成性能までは完全再現していません。
- 想定ランク、因子継承確率、相性値は非公式の推定です。
- 実際のゲーム画面と相違がある場合はゲーム内表示を優先してください。
