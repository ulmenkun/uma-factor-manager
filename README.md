# ウマ娘 技能試験・自動因子設計 Ver.3.1

ブラウザだけで動くオフライン版ツールです。`index.html` を開いて使用してください。

## Ver.3.1の主な変更

### サポートカードDB

- SSR 88枚、SR 21枚を収録
- 2025年1月29日以降に確認できた直近1年半のSSR 66枚を収録
- 因子周回で使いやすい旧SSR・SR、友人・グループカードも追加
- フォーエバーヤング、SSR駿川たづな「一杯のノスタルジア」、旧SSRたづなを収録
- 手動選択欄に `[スピード]` `[賢さ]` `[友人]` などのタイプを表示
- 選択後の6枠をタイプ別の背景色で表示

カードによって公開情報の充実度が異なるため、画面上で次のように区別しています。

- 詳細確認済み：ヒント・イベント・金スキルを個別収録
- スキル収録済み：確認できた取得スキルを収録
- メタデータのみ：カード名・タイプ・実装日を収録し、スキル詳細は未収録

### 家系図ごとの個別サポカ編成

③で本育成、親、祖父母、曾祖父母の15対象を切り替えられます。

- 各ウマ娘ごとに別の育成シナリオと6枚編成を保存
- そのウマ娘へ配置した白因子を取得できるカードを優先
- 所持カードから5枚、未所持カードから最適な1枚をフレンド枠へ配置
- 育成ウマ娘本人のサポカと、同一キャラクターの重複を除外
- ラーメンシナリオでは新SSRたづなを必須候補として扱う
- ラーメンでは原則として新たづな＋スピード2＋賢さ1＋必要スキルを取れる分散枠を優先

### 白・金スキルと技能試験効率

登録スキルは418件です。白スキルだけでなく、収録サポカから取得できる金スキルも本育成画面に表示します。

技能試験効率は次の考え方で計算します。

- 白スキル：適性補正後の基礎評価点＋400
- 金スキル：適性補正後の基礎評価点＋1,200
- 進化スキル：適性補正後の基礎評価点＋1,500
- ◎スキル：追加の固定400点なし
- 効率＝技能試験で増える点数 ÷ ヒントLv反映後の実消費SP

ヒントLvは0～5をタップで変更でき、必要SPと技能試験効率が即時に変わります。

公開資料で正確な基礎SP・評価点を確認できなかったスキルは空欄にせず、同系統スキルからの暫定値を入れています。暫定値は画面に「暫定値」と表示され、確定値と区別できます。

### 本育成の評価・技能試験ポイント

本育成ウマ娘をタップすると以下を入力できます。

- 5ステータス
- 固有スキルLv
- 取得スキルとヒントLv
- 使用可能スキルポイント
- G1・G2・G3・OPの勝利数
- その他の通常評価点、技能試験ボーナス

「技能試験ポイント最大で自動振分」は、所持SP内で技能試験ポイントが最大になる組合せを0/1ナップサック法で選びます。

表示は次の2種類を分離しています。

- 想定評価点・想定ランク：通常育成評価の概算
- 技能試験ポイント：通常評価＋スキル固定点＋ステータス加点＋レース加点＋入力ボーナス

## データ保存

- ブラウザのローカルストレージへ自動保存
- Ver.2.9系の保存データを引き継ぎ
- JSONバックアップの保存・読込に対応
- ブラウザデータを消すと自動保存内容も消えるため、重要な設計はバックアップしてください

## 注意事項

- サポカのヒント取得、イベント取得、金スキルの公開情報は更新や修正が入ることがあります。
- 「メタデータのみ」と表示される最新カードは、カード自体は編成できますが、必要スキルのカバー判定には十分反映されません。
- スキルの前提関係、下位・上位スキルの同時取得制限、進化条件、シナリオ固有の細かな育成性能までは完全再現していません。
- 想定ランク、因子継承確率、相性値は非公式の推定です。
- 実際のゲーム画面と相違がある場合はゲーム内表示を優先してください。
