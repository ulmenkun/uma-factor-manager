# ウマ娘 技能試験・自動因子設計 Ver.4.4

Ver.4.4は、Ver.4.3で追加した赤因子・ダートG1相性ローテ設計を引き継ぎつつ、起動時に発生していた表示エラーを修正した再構成版です。

## Ver.4.4の修正

- Ver.4.3で欠落していた `finalTargetRedStars()` を復元し、起動直後の「読み込みエラー」を修正
- クリスエスの赤因子設計を **本育成開始時：マイルA・追込B** で固定
- 追込の最終目標適性は従来どおりA。開始時Bから育成中継承でAを狙う
- Ver.4.3の家系図、赤因子配分、ダートD逆算、G1相性ローテ機能を維持
- バックアップファイル名をv4.4へ更新

## 既定のクリスエス設計

- [Jetblack Automaton] シンボリクリスエス
  - 初期：マイルE・追込D
  - 赤因子による本育成開始時：**マイルA・追込B**
  - 最終目標：マイルA・追込A（追込Aは育成中継承を狙う）
- マイル側の最終親：ラインクラフト
- 追込側の最終親：ステイゴールド
- ラインクラフト／ステイゴールドは、親作成時にダート G → D 以上となるよう下位世代のダート赤因子を自動配分
- ダートG→Dには合計7★以上が必要。★3中心では3枠（9★）を基本に割り当て

## 家系図の赤因子表示

- 親・祖父母・曾祖父母ごとに赤因子の種類と★数を表示
- ラインクラフト／ステイゴールドをダートDにするため、祖父母・曾祖父母の6因子で現在何★ダートを積んでいるかを表示
- 祖父母自身をダートDで周回する場合は、表示中の曾祖父母2人だけで不足する分を「表示外の父母4枠であと何★必要か」と逆算表示
- 候補変更後は下位候補を再計算

## 相性ローテ

- 親2人が共通して勝ちやすいG1を自動選択
- 相性上昇目的でダートG1を優先
- 赤因子による育成開始時の適性上昇を加味して出走可否を判定
- 育成目標・シナリオ競合と同ターンのレースは除外

## データ更新

`.github/workflows/update-uma-data.yml` は今回ユーザーから提供された最新版を収録しています。


## Ver.4.4 UI調整
- 「相性アップ用のダートG1ローテと必要赤因子」は常時ONで自動採用します。切替チェックボックスは表示しません。
- 長い「赤因子・相性ローテ設計」は初期表示では隠し、家系図を優先表示します。
- 家系図下の「赤因子・相性ローテの詳細を見る」を開くと従来の詳細を確認できます。
- Ver.4.4 compact r3: 「赤因子・相性ローテ設計」は初期表示で必ず閉じ、家系図を優先表示。必要時のみ「赤因子・相性ローテの詳細を見る」から展開。
