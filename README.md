# ウマ娘 技能試験・自動因子設計 Ver.4.3

Ver.4.3では、Ver.4.1の必須赤因子設計に加え、ラインクラフト／ステイゴールドをダートDにするために祖父母・曾祖父母の6因子からダート★がいくつ必要か、現在どの個体が何★を担当しているかを表示します。

## Ver.4.3の主な変更

- 本育成の初期適性と目標適性から、6枠の赤因子を自動配分
- シンボリクリスエス既定設定では、距離適性を優先してマイルAを確保しつつ追込も最大化
- ラインクラフト／ステイゴールドなどダートGの親は、ダートD以上になるよう祖父母・曾祖父母のダート赤因子を自動配分
- 各祖父母・曾祖父母は、自分自身が指定赤因子を作りやすい適性Aの候補を優先
- ダート赤の曾祖父母はオグリキャップ、エルコンドルパサー、イナリワン、アグネスデジタル等の自然ダート適性が高い候補を優先
- 親2人が共通して勝ちやすいG1を自動選択。ダートG1は相性上昇目的で高めに優先
- 家系図上に各個体の推奨赤因子、開始ダート適性、最終育成開始時の赤因子結果を表示
- 赤因子・ローテ設計欄に、各ウマ娘へ付ける赤因子の一覧と共通ダートG1を表示
- ラインクラフトとステイゴールドの初期適性を最新データで再確認・修正

## 既定のクリスエス設計

最終育成はマイルE→Aに必要な赤因子を優先し、追込Dは残りの赤因子でBまで上げ、育成中の継承でAを狙う設計を基本とします。

ラインクラフトはダートG→D以上、ステイゴールドはダートG→D以上かつ追込C→Aを親作成時に狙えるよう、曾祖父までの赤因子を配分します。ステイゴールドはマイルGのため、両親共通のダートローテは主に中距離ダートG1を優先します。

## 注意

赤因子の継承発生率など公式非公開の内部抽選は推定できないため、ツールは開始時の適性上昇に必要な赤因子★数と、公開されている相性の仕組みを使って設計しています。レース目標と同ターンのG1は自動ローテから除外します。


### Ver.4.3追加
- 父母をダートDにするための最低必要ダート★、現在値、あと何★かを表示
- 祖父母①②・曾祖父母①〜④の赤因子を一覧化し、ダート担当を強調
- 家系図カードにも「親ダート用 +n★」を表示


## Ver.4.3 追加
- クリスエスの祖父母をダートDで因子周回するために、表示中の曾祖父母2人＋その父母4人（表示外）まで含めた6因子のダート★必要量を逆算表示。
- 祖父母ごとに自然ダート、Dまでの最低★、表示中2親からのダート★、表示外4枠で不足する★、★3中心の必要枠数を表示。
- 家系図の祖父母カードにも「自身ダートD：表示外○★」を表示。
