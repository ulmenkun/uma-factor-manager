# ウマ娘 技能試験・自動因子設計 Ver.3.4

ブラウザで動くウマ娘の因子設計・サポカ編成・技能試験ポイント試算ツールです。

## Ver.3.4の変更

### PAT不要の「最新データを確認」方式

Webページから次の入力欄と処理を削除しました。

- GitHubユーザー名
- リポジトリ名
- ブランチ名
- ワークフロー名
- Personal Access Token（PAT）
- Safariへのトークン保存
- WebページからGitHub Actionsを起動する処理

ページは `data/latest-data-pack.json` を読み込み、現在端末で使用中のデータとの差分だけを表示します。秘密情報やGitHubログイン情報を入力する必要はありません。

### 更新の流れ

1. GitHub Actionsが毎日1回、公開情報を確認して更新パックを作成します。
2. Webページで「最新データを確認」を押します。
3. 新しいデータがある場合は追加・更新件数を確認します。
4. 「この更新を適用」を押します。

GitHub Actionsは日本時間の午前5時20分ごろに実行される設定です。GitHub側の都合で開始が遅れる場合があります。必要なときはGitHubのActions画面から手動実行もできますが、WebページにPATを入力する必要はありません。

Ver.3.3でSafariにPATを保存していた場合も、Ver.3.4を一度開くと旧トークン保存領域を自動削除します。

## データ収集の方針

- GameToraの公開マニフェスト、サポートカード一覧、各カード詳細を参照
- 既存の精査済みカード情報・SP・評価点は維持
- 新規で数値未確認のスキルは暫定値として追加
- 暫定値は画面上で確定値と区別
- 公開ページ1件の形式が変わっても、ほかのカードの収集は継続

## 主な機能

- SSR・SRサポカDB、所持チェック、タイプ別色分け
- 本育成・親・祖父母・曾祖父母の15対象別サポカ編成
- 必要白因子を取得しやすい所持5枚＋フレンド1枚の自動編成
- 育成シナリオ別の編成補正
- 白・金・進化スキルと技能試験効率
- ヒントLvを反映した実消費SP
- 所持SP内で技能試験ポイントを最大化する自動振分
- 想定評価点・想定ランク・技能試験ポイント
- 家系図、因子、継承確率、G1ボーナス

## データ形式

`data/latest-data-pack.json` は次の情報を持つ更新パックです。

- `schemaVersion`
- `version` / `generatedAt`
- `supportCards`
- `skills`
- `removedSupportCardIds` / `removedSkillNames`
- `externalHashes`
- `releaseNotes`

更新パックは本体データへマージされ、ブラウザのローカルストレージへ保存されます。所持サポカ、家系図、編成、ヒントLvなどの利用者データはGitHubへ送信されません。

## 注意事項

- 公開ページの構造変更により一部データを取得できなくなる場合があります。
- 自動追加された未確認スキルのSP・評価点は暫定値です。
- スキルの前提関係、進化条件、シナリオ固有性能までは完全再現していません。
- 想定ランク、因子継承確率、相性値は非公式の推定です。
- 実際のゲーム画面と相違がある場合はゲーム内表示を優先してください。
