# ウマ娘 技能試験・自動因子設計 Ver.3.8

技能試験向けのスキル効率、因子家系図、ウマ娘ごとのサポカ編成をまとめたブラウザツールです。


## Ver.3.8の変更

- ①で新しく選択した緑○・レース場○を、選択中の区分へ即時表示し、②の全ウマ娘の因子候補にも反映
- Ver.3.7以前に非表示になっていた選択済み緑○を初回起動時に復元
- ②の削除条件を「因子選択なし」から「習得チェックなし」へ変更
- 未習得スキルを削除すると、そのウマ娘の因子候補チェックと★を解除して一覧から非表示

- 川崎記念・かしわ記念・マイルCS南部杯（クラシック／シニア）をレース因子ありへ修正
- 上記レースでレース因子★0～3を選択可能
- ④のレース一覧と②の各ウマ娘のレース因子欄の両方へ反映
- このツールに登録しているG1はすべてレース因子を持つ前提でデータ検査を追加


### ②のウマ娘選択と因子設定を分離

- 「ウマ娘を選ぶ」と「因子を設定する」を別々の枠で常時表示
- 現在選択中のウマ娘名を両方の枠に表示
- 候補一覧は枠内スクロールにして、因子設定まで移動しやすく変更

### ④のレース設定を各ウマ娘へ反映

- ④で選択したレースを、②の各ウマ娘の「レース因子」に初期表示
- 登録しているすべてのG1／Jpn1を、レース因子★と共通G1勝利の記録用として表示
- 各ウマ娘だけにレースを追加可能
- 不要なレースを各ウマ娘の一覧から削除可能
- 「④の選択に戻す」で個別追加・削除をリセット可能
- 適性B未満のレースは警告表示

### 各ウマ娘のスキル因子一覧を整理

- 一覧に表示中で、「習得」にチェックが付いていないスキルを一括削除
- 未習得スキルを1件ずつ削除
- 削除したスキルをまとめて復元
- 削除は対象ウマ娘の表示だけに作用し、①の白因子選択や他のウマ娘には影響しない

## Ver.3.5の変更

### 取得スキルデータを再調査

- Ver.3.4で取得スキルが空または少なかった直近SSR等29枚を再調査
- ヒント（トレーニング）取得、イベント取得、金スキルを分離
- U-toolsを主データ、GameWith・Game8を副照合、GameToraを新規カード検出に使用
- 新たづな、フォーエバーヤング、ヴィクトワールピサ、マルシュロレーヌ、タップダンスシチー、サクラチヨノオー等を含む
- 未登録だったスキルを追加し、金スキル区分も補正
- 精査済みのSP・評価点は自動更新で上書きしない

### 日次更新を複数サイト照合方式へ変更

GitHub Actionsの更新処理は、GameToraだけでなくU-toolsの「イベントで取得」「トレーニングで取得」も取得します。ページ構造変更時に最近の重要カードが空にならないよう、複数サイトで確認済みの補完表も同梱しています。

### 外部アクセス確認（概算）

- 管理者端末を1台設定可能
- その端末を除き、別端末・別ブラウザから初めて開かれた件数の目安を表示
- 氏名、GitHubユーザー名、家系図、所持サポカ、入力した育成情報は送信しない
- 公開カウンターを使うため、ボット、Cookie削除、広告ブロック、複数ブラウザ等の影響を受ける概算値
- 誰がアクセスしたか、IPアドレス、閲覧内容はツール画面には表示しない

最初に自分のiPhoneで「この端末を管理者端末にする」を押してください。すでに一般アクセスとして計測されていた場合は、可能な範囲で1件差し引きます。

## 公開方法

ZIPを解凍し、リポジトリへフォルダ構成を保ったまま上書きしてください。

```text
index.html
visitor-stats.js
data/
  latest-data-pack.js
  latest-data-pack.json
tools/
  update_data.py
  curated_patch_v35.py
  requirements-update.txt
.github/workflows/
  update-uma-data.yml
```

GitHub Pagesでは家系図・所持情報等は各ブラウザのlocalStorageに保存され、GitHubリポジトリへ自動送信されません。
