# ウマ娘 技能試験・自動因子設計 Ver.3.2

ブラウザで動くウマ娘の因子設計・サポカ編成・技能試験ポイント試算ツールです。

## Ver.3.2の主な変更

### Webページ内のデータ更新センター

ページ下部の「最新サポカ・スキルデータ」から、ツール本体を作り直さなくてもデータパックを更新できます。

- 「最新データを確認」で公開JSONとの差分を確認
- サポカ追加・サポカ更新・スキル追加・スキル更新の件数を表示
- 更新内容を確認してから適用
- 1日1回の起動時自動確認
- 任意で新しい更新の自動適用
- 更新JSONファイルの手動読込
- 任意の更新パックURLを設定
- 問題がある場合は本体同梱データへ戻す

オンライン更新を適用しても、次の利用者データは保持されます。

- 所持サポカのチェック
- 手動追加サポカと手動スキル
- 家系図・因子・G1設定
- ウマ娘ごとのサポカ編成
- 本育成のステータス、取得スキル、ヒントLv

### 自動データ生成

`.github/workflows/update-uma-data.yml` を同梱しています。GitHubへ配置してActionsを有効にすると、毎日5:20ごろ（日本時間）に公開データの変更を確認し、`data/latest-data-pack.json` を更新します。

自動収集では次の方針を採用しています。

- 新規SSR・SRサポカと取得スキル名を検出
- 既存の精査済みカード情報・SP・評価点は維持
- 新規で数値未確認のスキルは暫定値として追加
- 暫定値は画面上で確定値と区別
- 1件のページ形式変更があっても、ほかのカード更新は継続

### 利用方法

#### GitHub Pagesなどで公開する場合

1. ZIPの中身をGitHubリポジトリへ配置します。
2. GitHub Actionsを有効にします。
3. GitHub Pagesを有効にします。
4. Webページを開くと、同じサイト内の `data/latest-data-pack.json` を1日1回確認します。

この方法では、利用者がこのツールへ改修を依頼しなくても、Actionsが作成した最新パックをページ上から適用できます。

#### ZIPを端末内で直接開く場合

`index.html` を直接開いてもツール本体は使えます。ただし、ブラウザのセキュリティ制限により同じフォルダのJSONを自動取得できない場合があります。その場合は次のいずれかを使います。

- 「更新パックURL」に公開JSONのURLを設定
- ダウンロードした `latest-data-pack.json` を「更新JSONを読み込む」から選択
- ローカルWebサーバーでフォルダを開く

## Ver.3.1までの主な機能

### サポートカードDB

- SSR 88枚、SR 21枚を収録した初期データ
- 直近1年半のSSR、因子周回向け旧SSR・SR、友人・グループカード
- フォーエバーヤング、新旧たづなを収録
- 手動選択欄に `[スピード]` `[賢さ]` `[友人]` などのタイプを表示
- 選択後の6枠をタイプ別の背景色で表示

### 家系図ごとの個別サポカ編成

③で本育成、親、祖父母、曾祖父母の15対象を切り替えられます。

- 各ウマ娘ごとに別の育成シナリオと6枚編成を保存
- そのウマ娘へ配置した白因子を取得できるカードを優先
- 所持カードから5枚、未所持カードから最適な1枚をフレンド枠へ配置
- 育成ウマ娘本人のサポカと同一キャラクター重複を除外
- ラーメンシナリオでは新SSRたづなを必須候補として扱う

### 白・金スキルと技能試験効率

- 白スキル：適性補正後の基礎評価点＋400
- 金スキル：適性補正後の基礎評価点＋1,200
- 進化スキル：適性補正後の基礎評価点＋1,500
- ◎スキル：追加の固定400点なし
- 効率＝技能試験で増える点数 ÷ ヒントLv反映後の実消費SP

本育成画面では、所持SP内で技能試験ポイントが最大になる組合せを0/1ナップサック法で選びます。

## データ形式

`data/latest-data-pack.json` は次の情報を持つ更新パックです。

- `schemaVersion`
- `version` / `generatedAt`
- `supportCards`
- `skills`
- `removedSupportCardIds` / `removedSkillNames`
- `externalHashes`
- `releaseNotes`

更新パックは本体データへマージされ、ブラウザのローカルストレージへ保存されます。

## 注意事項

- 自動収集は公開ページの構造変更により一部取得できなくなる可能性があります。
- 自動追加された未確認スキルのSP・評価点は暫定値です。精査済み値が配布された場合は更新パックで上書きされます。
- スキルの前提関係、下位・上位スキルの同時取得制限、進化条件、シナリオ固有の細かな育成性能までは完全再現していません。
- 想定ランク、因子継承確率、相性値は非公式の推定です。
- 実際のゲーム画面と相違がある場合はゲーム内表示を優先してください。
