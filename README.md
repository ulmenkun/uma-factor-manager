# ウマ娘 技能試験・自動因子設計 Ver.4.4 r12

Ver.4.4は、Ver.4.3で追加した赤因子・ダートG1相性ローテ設計を引き継ぎつつ、起動時に発生していた表示エラーを修正した再構成版です。

## Ver.4.4 r12（2026-09-19）

- クリスエス技能試験用の直親を **エピファネイア＋ステイゴールドで固定**。継承進化を最優先する方針を固定条件化
- クリスエスの最終目標を **マイルA・追込A** として自動設計。赤因子6枠では開始A/Aが同時達成できないため、開始時は **マイルA・追込B**、育成中継承で追込Aを狙う
- 祖父母・曾祖父母の自動選定を、各カード単体の候補点ではなく **家系全体の組合せ探索** に変更
- 相性評価は **素の相性値 + 共通G1数×3** を同じポイントとして合算。父母・祖父母の路線が違うことで失うG1ボーナスと、素相性の差を直接比較する
- G1ローテは最終クリスエスで参照される5本（親同士、各親と祖父母2人ずつ）をターン単位で同時評価し、そのターンで最もG1ボーナスを稼げるレースを自動選択
- U-toolsの実相性値をエピファネイア／ステイゴールド周辺と主要候補に追加。未登録ペアのみ適性グループから推定し、根拠タブに実相性参照数を表示
- シンボリクリスエス本人は祖父母・曾祖父母の自動候補から除外
- 距離C以上を通常ローテ可、Dは継承UP前提で許容するr11方針を維持

## Ver.4.4 r11（2026-09-09）

- 直親の第一候補を **エピファネイア＋ステイゴールド** に変更。参考note公開時点ではエピファネイアが未考慮のため、継承進化2人を最優先
- 距離Cを通常ローテ可、**距離Dは継承アップ前提の許容ライン**として扱う
- ステイゴールド追込側は、6赤因子枠では「マイルD・ダートD・追込A」を開始時に完全同時達成できないため、**開始マイルD・ダートE・追込B → 育成中継承でマイルC・ダートD・追込A** を狙うリスク許容設計を追加
- レース因子は赤適性を直接上げるものではない点をUIに明記。代わりに **共通G1ボーナス（同GI1種につき+3）＋レース因子で得られる高効率スキル** をローテ選択に加点。ステゴはクラシック4月以降に継承アップ成功を仮定してダートG1を再判定
- 全日本ジュニア優駿（川崎・ダート・マイル）は「パワー＋ナイター○」、川崎記念（川崎・ダート・中距離）は「賢さ＋川崎レース場○」。技能試験効率の高いレース因子を同ターン候補の中で優先。ただし共通G1を崩す場合は相性損失も比較
- 「おすすめ選定の根拠」タブにレース因子価値と継承アップ前提を表示

## Ver.4.4 r10（2026-09-08）

- 因子周回の距離ローテ成立ラインを **B以上 → C以上** に変更。マイル・中距離・長距離はC以上なら「ローテ可」と判定
- 直親は従来どおり **継承進化を最優先**。3距離C以上＋ダートD＋担当赤因子を6枠で両立できるかを成立条件にして、その中で継承進化人数→技能試験点→素の相性＋共通G1ボーナス→赤因子負担の順に比較
- 祖父母・曾祖父母は3距離C以上を強く優先するが、C未満を機械的に最下位へ固定しない。**素の相性＋共通G1数×3** を同じ相性値として比較し、GIボーナスで逆転できるよう変更
- ml'p「0から始める技能試験:因子周回編」（2026-08-26）を設計方針の参考に追加。記事の「親は相性が悪くても進化可能な継承固有持ちを優先」「祖は欲しい適性・相性・GI勝利数を考慮」「同一GI 1種につき相性+3」を反映
- 既存r9保存データは初回起動時に自動でおすすめ家系図を再計算

## Ver.4.4 r9（2026-09-08）

- 直親おすすめの優先順位を修正。**ローテが物理的に成立しない候補だけを除外し、その中では継承進化を最優先**
- 直親ペアの比較順を、①利用可能な継承進化の人数、②継承進化の技能試験点、③相性値＋共通G1ボーナス、④赤因子負担・終了時Aへのリスク、の順に変更
- 「3距離ローテ優先」が継承進化より上に見えていた説明文を修正。3距離B以上＋ダートD＋担当赤因子はおすすめ候補に入るための成立条件で、順位付けの第一優先は継承進化
- ステイゴールドのようにマイルBを作れず共通ローテそのものが成立しない場合は、継承進化持ちでも直親候補から除外。これは継承進化の優先度を下げるのではなく、ローテ不成立を候補外とする扱い
- おすすめ選定根拠タブにも「継承進化最優先」の比較順を明記し、次点候補にも継承進化人数・技能試験点を表示

## Ver.4.4 r8（2026-09-08）

- 家系図おすすめを「マイル・中距離・長距離の3距離G1ローテ可否」込みで再設計。直親は3距離すべてB以上＋ダートD＋狙う赤因子を6枠で両立できる候補を優先
- ステイゴールドのように、追込赤＋ダートDを作るとマイルBまで上げられず共通ローテを組めない直親は自動おすすめから大きく後退
- 直親候補を継承進化持ち3人だけに限定せず、登録済み育成ウマ娘全体から比較。継承進化点は加点要素として残す
- 直親の順位は「基礎相性＋共通G1ボーナス（共通G1 1種につき+3）」を中心に、継承進化点と赤因子作成負担を加味
- 祖父母・曾祖父母も3距離B以上を強く優先し、子との共通G1候補数をおすすめ点へ加算。相性を落としすぎる場合は総合点で比較
- 家系図の下に「おすすめ選定の根拠を見る」を追加。直親ペアの相性/G1/継承進化/赤因子負担と、各祖先の3距離適性・相性・G1ボーナス・候補点を折りたたみ表示

## Ver.4.4 r7（2026-09-08）

- 技能試験向けサポカTOP5を「単体順位」から「5枚全体の組み合わせ評価」へ変更。既に別カードで取れる高効率スキルは大幅減点し、取得できるスキル種類数を優先
- 選択中の育成シナリオを編成評価へ反映。トレセン軒は新SSR駿川たづな＋スピード2＋賢さ1を軸、BEYOND DREAMSはSSRカジノドライヴ＋5タイプ以上・スピード1〜2枚を優先
- TOP5と下のおすすめサポカ自動編成で同じ「重複回避」評価を使用。所持5枚＋フレンド1枚の制約内で未取得の高効率スキルを増やすカードを優先
- TOP5は「自動編成」を押した時に更新。育成シナリオを変更した場合はいったんクリアし、再度自動編成するまで旧ランキングを表示しない
- TOP5欄はデフォルト非表示。「技能試験向けサポカTOP5を見る」を押した時だけ展開

## 既定のクリスエス設計

- [Jetblack Automaton] シンボリクリスエス
  - 初期：マイルE・追込D
  - 赤因子による本育成開始時：**マイルA・追込B**
  - 最終目標：マイルA・追込A（追込Aは育成中継承を狙う）
- 直親は **エピファネイア＋ステイゴールドで固定**。継承進化2人を最優先し、祖父母以下を実相性＋共通G1ボーナスで自動最適化
- r12では **マイル側エピファネイア＋追込側ステイゴールド** を固定直親として使用
  - クリスエスとの相性：エピファネイア18、ステイゴールド23
  - 親同士：エピファネイア×ステイゴールド20 → 3者基礎相性合計61
  - 比較：ラインクラフト＋ステイゴールドは 8＋23＋9＝40
- 継承進化は技能試験用の検証値 **1個1764点 / 200SP** として重視。発動条件そのものより査定を優先する
- 最終クリスエスへ渡す6枠は **マイル12★＋追込6★** を基本配分とし、初期マイルE→A・追込D→B。育成中の追込継承UPで最終追込Aを狙う
- ステイゴールド自身の因子周回は、距離Cを通常ローテ可・Dを継承UP前提の許容ラインとして、マイル／ダート／追込の赤因子負担と共通G1を同時評価
- ダートG→Dには合計7★以上が必要。★3中心では3枠（9★）を基本に割り当て
- 継承進化は直親からのみ。本人未所持ならフレンド因子を借りても進化不可なので、所持設定を入力した場合は自動ランキングに反映

## 家系図の赤因子表示

- 親・祖父母・曾祖父母ごとに赤因子の種類と★数を表示
- その時点で選ばれた直親をダートD以上にするため、祖父母・曾祖父母の6因子で現在何★ダートを積んでいるかを表示
- 祖父母自身をダートDで周回する場合は、表示中の曾祖父母2人だけで不足する分を「表示外の父母4枠であと何★必要か」と逆算表示
- 候補変更後は下位候補を再計算

## 相性ローテ

- 親2人が共通して勝ちやすいG1を自動選択
- 相性上昇目的でダートG1を優先
- 赤因子による育成開始時の適性上昇を加味して出走可否を判定
- 育成目標・シナリオ競合と同ターンのレースは除外
