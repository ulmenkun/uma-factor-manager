# ウマ娘 技能試験・自動因子設計 Ver.3.5

技能試験向けのスキル効率、因子家系図、ウマ娘ごとのサポカ編成をまとめたブラウザツールです。

## Ver.3.5の変更

### 取得スキルデータを再調査

- Ver.3.4で取得スキルが空または少なかった直近SSR等29枚を再調査
- ヒント（トレーニング）取得、イベント取得、金スキルを分離
- U-toolsを主データ、GameWith・Game8を副照合、GameToraを新規カード検出に使用
- 新たづな、フォーエバーヤング、ヴィクトワールピサ、マルシュロレーヌ、タップダンスシチー、サクラチヨノオー等を含む
- 未登録だったスキルを追加し、金スキル区分も補正
- 精査済みのSP・評価点は自動更新で上書きしない

### 日次更新を複数サイト照合方式へ変更

GitHub Actionsの更新処理は、GameToraだけでなくU-toolsの「イベントで取得」「トレーニングで取得」も取得します。ページ構造変更時に最近の重要カードが空にならないよう、複数サイトで確認済みの補完表も同梱しています。

### 外部アクセス確認（概算）

- 管理者端末を1台設定可能
- その端末を除き、別端末・別ブラウザから初めて開かれた件数の目安を表示
- 氏名、GitHubユーザー名、家系図、所持サポカ、入力した育成情報は送信しない
- 公開カウンターを使うため、ボット、Cookie削除、広告ブロック、複数ブラウザ等の影響を受ける概算値
- 誰がアクセスしたか、IPアドレス、閲覧内容はツール画面には表示しない

最初に自分のiPhoneで「この端末を管理者端末にする」を押してください。すでに一般アクセスとして計測されていた場合は、可能な範囲で1件差し引きます。

## 公開方法

ZIPを解凍し、リポジトリへフォルダ構成を保ったまま上書きしてください。

```text
index.html
visitor-stats.js
data/
  latest-data-pack.js
  latest-data-pack.json
tools/
  update_data.py
  curated_patch_v35.py
  requirements-update.txt
.github/workflows/
  update-uma-data.yml
```

GitHub Pagesでは家系図・所持情報等は各ブラウザのlocalStorageに保存され、GitHubリポジトリへ自動送信されません。
